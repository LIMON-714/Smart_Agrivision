Why Choose SmartAgriVision?

SmartAgriVision is an AI-powered web application designed to identify flowers, fruits and vegetables using advanced Deep Learning and Computer Vision technology.

Built with Django, YOLOv8 and OpenCV, our system provides image detection, video detection and real-time camera detection with a modern user interface and high accuracy.

  • Secure Django Framework
  • Responsive Web Application
  • User Friendly Dashboard
